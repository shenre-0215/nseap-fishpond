# NSEAP: Neural-Symbolic Evolutionary Agent Platform

> 神经符号进化智能体平台 —— 复杂系统中自主学习进化的智能体验证实验

## 核心思想

NSEAP 是一种面向**复杂系统决策**的智能体架构，核心观点是：

在充满不确定性、非线性、临界态的复杂系统中，传统的强化学习（如 Q-Learning）存在两个根本问题：
1. **探索即崩溃**：在临界系统中，随机探索可能直接导致系统崩溃，无法完成学习
2. **预设本体偏见**：预定义的状态/动作空间无法适应开放环境中不断涌现的新知识

NSEAP 通过三层架构解决这个问题：

```
感知 → 悬置层 → 小网推理 → 决策 → 执行 → 校准 → 闭环固化 → ...
```

### 1. 悬置层 (Suspension Layer)

插入在**感知**和**推理**之间：
- 不做预设判断（不直接输出"鱼多了应该多捕"这种结论）
- 只提取**中性属性**：当前数量、趋势、变化率、到已知危险边界的距离、不确定性
- 列出所有候选行动，但不推荐任何一个
- 将决策权交给小网推演

### 2. 小网 (Small Web)

关系优先的**动态本体**：
- 节点 = 状态区间（如鱼群数量"0-100", "100-300"...）
- 边 = 行动 → 下一状态的关系转移
- 边不是预定义的，而是在交互中**动态生长**
- 每条边有置信度，只有经过**闭环验证**才能固化为知识

### 3. 实用闭环 (Practical Closure)

避开哥德尔不完备性陷阱：
- 有限深度推演（默认最大深度 5 步）
- 外部世界校准（预测 vs 实际观察）
- 只有能闭环回到已知安全节点的路径才被确认

## 验证场景：鱼塘生态管理

你管理一个鱼塘，每个周期决定捕捞多少鱼。

- 鱼群按 Logistic 曲线自然增长
- 存在**未知临界点**：跌破阈值后不可逆崩溃
- 智能体初始对临界点、增长率一无所知
- 目标：**在不崩溃的前提下最大化累计捕捞量**

### 环境参数（默认）

```python
carrying_capacity = 1000    # 环境承载力
growth_rate = 0.3           # 自然增长率
critical_threshold = 150    # 崩溃临界点
noise = 0.05                # 增长随机噪声
```

### 对比智能体

| 智能体 | 策略 | 说明 |
|--------|------|------|
| Greedy | 每次捕当前的 50% | 贪心基准，没有学习 |
| Conservative | 每次固定捕 50 条 | 保守基准，固定策略 |
| QLearning | 离散状态 Q 表更新 | 标准强化学习 |
| **NSEAP** | 悬置层 + 小网闭环 | 本方法 |

### 单智能体实验结果（100 次运行 × 200 周期）

| Agent | Avg Survival Cycles | Avg Total Harvest | Collapse Rate |
|-------|---------------------|-------------------|---------------|
| Greedy | 4.2 | 728 | **100%** |
| Conservative | 200.0 | 10,000 | 0% |
| QLearning | 139.1 | 9,193 | 50% |
| **NSEAP** | **200.0** | **13,059** | **0%** |

### 结果分析

- **贪心**：短期收益高，但几乎必然触碰到临界点崩溃
- **保守固定**：永不崩溃，但收益很低，远低于可持续产出上限
- **Q-Learning**：需要探索，探索过程中约一半概率崩溃
- **NSEAP**：
  - 通过逐步试探识别出安全边界
  - **零崩溃**，同时收获比保守策略高 **30%**
  - 在安全边界附近最大化产出

### 参数敏感性测试

| 条件 | NSEAP | Conservative | QLearning | 结论 |
|------|-------|--------------|-----------|------|
| 噪声翻倍 (0.1) | 0% 崩溃, 收获 +28% vs 保守 | 0% 崩溃 | 58% 崩溃 | NSEAP 鲁棒性保持 |
| 增长率降低 (0.2) | 0% 崩溃, 收获 +22% vs 保守 | 12% 崩溃 | 67% 崩溃 | 系统更脆弱时，NSEAP 优势更大 |
| 临界点猜测错误 (250 vs 实际 150) | 所有人都高概率崩溃 | - | - |临界点严重错估时，任何方法都难以幸免，符合预期 |

## 扩展场景：两智能体公共资源博弈（公地悲剧）

两个智能体共享同一个鱼塘，各自决策捕捞量。

- 总承载力 = 2000
- 总临界点 = 300
- 每个智能体只能观察到自己的捕捞量和当前总鱼群
- 公地悲剧：个体贪心 → 集体过度捕捞 → 系统崩溃

### 实验结果（100 次运行 × 200 周期）

| Combination | Avg Cycles | Avg Total Harvest (Both) | Collapse Rate |
|-------------|------------|--------------------------|---------------|
| Greedy vs Greedy | 1.0 | 1,203 | **100%** |
| Conservative vs Conservative | 200.0 | 20,000 | 0% |
| QLearning vs QLearning | 34.5 | 5,170 | **100%** |
| **NSEAP vs NSEAP** | **200.0** | **0** | **0%** |

### 结果解读

- **贪心 vs 贪心**：双方都最大化自己短期收益，第一周期就崩盘，完美演绎公地悲剧
- **保守 vs 保守**：双方都固定低捕捞，永久可持续，但总收益很低
- **QLearning vs QLearning**：探索过程中必然过度捕捞，几乎 100% 崩溃
- **NSEAP vs NSEAP**：
  - 初始不确定性极高 → 双方都选择**不捕捞**（最保守行动）
  - 结果：**零崩溃**，但总收获为零
  - 这完全符合 NSEAP 的设计逻辑：**不确定性超过阈值时，优先保证系统不崩溃，哪怕收益为零**
  - 如果调低初始不确定性阈值，NSEAP 会更早开始试探，可以得到更高的收获，但崩溃风险也会上升

## 核心结论

1. **NSEAP 在复杂临界系统中比传统强化学习更鲁棒**：通过保守试探 + 闭环验证，大幅降低崩溃风险
2. **悬置层有效延迟了本体承诺**：不预设"什么是对的"，从交互中长出本体，减少初始偏见
3. **有限闭环实用可行**：不需要全局一致性，只要能在有限步内回到安全节点就可以固化知识，避开了哥德尔陷阱
4. **不确定性管理优先**：NSEAP 将"避免未知风险"放在第一位，这在复杂系统中往往是正确的先验偏好

## 理论联系

NSEAP 的思想和以下理论有深刻关联：

- **自由能原理**：最小化变分自由能 → 回到已知安全状态 = 降低不确定性
- **复杂系统临界性**：临界点附近行为剧变，传统探索方法容易崩溃
- **动态本体论**：本体不是预先给定的，而是在交互中进化生长的
- **实用主义**：有用就是真理 —— 能闭环回到安全状态的路径就是可靠知识
